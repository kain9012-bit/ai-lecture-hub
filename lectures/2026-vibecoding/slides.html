사용 시점

도구를 만들기 전, 바로 코드를 시키지 않고 좋은 개발 요청문부터 만들게 합니다.

AI가 빠진 조건을 되물어주고, 마지막에 붙여넣을 최종 프롬프트를 만들어줍니다.

요구사항 정리질문 생성최종 프롬프트
META PROMPT
너는 업무도구 제작을 위한 메타 프롬프트 작성 도우미야.

나는 코딩 초보자이고, AI를 활용해서 작은 업무도구를 만들고 싶어.
하지만 처음부터 어떻게 요청해야 할지 잘 모르겠어.

내가 만들고 싶은 도구를 설명하면, 너는 다음 순서로 도와줘.

1. 내가 만들고 싶은 도구의 목적을 정리해줘.
2. 입력값, 처리 과정, 출력 결과를 구분해서 정리해줘.
3. 실행 환경을 정리해줘. (HTML / 파이썬 / 확장 프로그램 / 웹사이트)
4. 빠진 조건이 있으면 나에게 질문해줘.
5. 개인정보, 내부자료, 보안상 주의할 점을 확인해줘.
6. 마지막에 다른 AI 채팅창에 그대로 붙여넣을 최종 프롬프트를 작성해줘.

최종 프롬프트는 다음 형식으로 만들어줘.
- 역할 부여 / 도구의 목적 / 입력값 / 주요 기능 / 출력 결과
- 디자인·사용성 조건 / 실행 환경 / 예외 처리 / 보안 주의사항 / 전체 코드 제공 요청

이제 내가 만들고 싶은 도구를 설명할게.

WHAT TO DETECT

잡아내야 할 여섯 가지 유형

형식 오류이메일에 @가 없음, 전화번호 자리수·형식이 이상함
공란이메일이나 전화번호가 비어 있음
완전 중복같은 이메일·전화번호가 그대로 반복됨
대소문자 중복User@… 와 user@… 를 같은 값으로 봐야 함
앞뒤 공백 중복값 앞뒤 공백만 다르고 실제로는 같은 값
정규화 중복010-1234-5678 과 01012345678 처럼 형식만 다른 같은 번호
이 여섯 가지를 AI에게 정확히 설명하는 것이 이번 실습의 핵심입니다. 단순 중복만 잡으면 절반은 놓칩니다.

HTML명단 붙여넣기6가지 검사
HTML TOOL PROMPT
직원 명단에서 이메일·전화번호의 오류와 중복을 찾아주는
HTML 검사 도구를 만들고 싶어. 나는 코딩 초보자야.

[입력 데이터]
엑셀 "명단" 시트를 통째로 복사해 붙여넣어. 열 순서는
일련번호 / 소속기관 / 소속 실·국 / 소속부서 / 직급 / 성명 / 이메일 / 전화번호 야.
첫 줄은 머리글이고, 열은 탭으로 구분돼. 약 1000행이야.

[조건]
1. 외부 라이브러리 없이 하나의 index.html 파일로 만들어줘.
2. 큰 붙여넣기 입력칸과 [검사하기] 버튼을 넣어줘.
3. 이메일 열과 전화번호 열을 기준으로 다음 6가지를 검사해줘.
   ① 형식 오류 - 이메일에 @/도메인 없음, 전화번호 자리수·형식 이상
   ② 공란 - 이메일 또는 전화번호가 비어 있음
   ③ 완전 중복 - 같은 값이 그대로 반복
   ④ 대소문자 중복 - 이메일은 대소문자를 무시하고 같은 값으로 판단
   ⑤ 앞뒤 공백 중복 - 앞뒤 공백을 제거한 뒤 같은 값이면 중복
   ⑥ 정규화 중복 - 전화번호는 숫자만 남겨 비교(하이픈·공백 무시)
4. 결과 표에 일련번호·성명·이메일·전화번호·검사결과·문제유형을 보여줘.
5. 상단에 유형별 건수 요약(형식오류 N, 공란 N, 중복 N…)을 보여줘.
6. [오류·중복만 보기] [전체 보기] [입력 지우기] 버튼을 넣어줘.
7. 오류 행은 눈에 띄게 색으로 표시해줘.
8. 공공기관 업무도구처럼 깔끔하게, 모바일에서도 보이게 만들어줘.

초보자가 바로 저장해 실행할 수 있게 index.html 전체 코드를 한 번에 제공해줘.

유형 04 · LLM INTEGRATION
TYPE 04 · LLM 연결하여 요약

페이지 내용을 AI로 3줄 요약합니다

방식 A · 외부 API (OpenAI / Claude)
const text = document.body.innerText.slice(0,1000);
const res = await fetch(
  "https://api.openai.com/v1/chat/completions",
  { method:"POST",
    headers:{ "Authorization":"Bearer KEY" },
    body: JSON.stringify({
      model:"gpt-4o",
      messages:[{role:"user",
        content:"3줄 요약:\n"+text}]
    })
  });
const d = await res.json();
alert(d.choices[0].message.content);
방식 B · Local LLM (Ollama)
// ollama run llama3 으로 로컬 서버 실행
const text = document.body.innerText.slice(0,1000);
const res = await fetch(
  "http://localhost:11434/api/generate",
  { method:"POST",
    body: JSON.stringify({
      model:"llama3",
      prompt:"3줄 요약:\n"+text,
      stream:false
    })
  });
const d = await res.json();
alert(d.response);
API Key를 Console에 직접 입력하면 화면에 노출됩니다. 실습용 Key를 쓰고 사용 후 즉시 폐기하세요. 외부 API는 데이터가 외부로 전송되고, Local LLM은 완전 로컬 처리입니다.

① 먼저 메타 프롬프트로 요청문을 만듭니다

사용 시점

코드를 바로 달라고 하지 않고, “이 문제를 풀 좋은 요청문을 만들어줘”라고 먼저 시킵니다.

단, 콘솔에서 바로 테스트할 수 있는 코드가 나오도록 조건을 담게 합니다.

메타 프롬프트콘솔 테스트용요청문 완성
META PROMPT
너는 개발 요청문(프롬프트) 작성 도우미야. 나는 코딩 초보자야.
아래 문제를 풀 코드를 받고 싶은데, 먼저 크롬 개발자 도구 콘솔(F12)에
붙여넣어 바로 테스트할 수 있는 자바스크립트가 나오도록,
내가 새 AI 채팅창에 그대로 붙여넣을 '좋은 요청문'을 만들어줘.

[문제 상황]
- 전북교육청 '한줄소감' 게시판 2026년 글 491건을 엑셀로 모으고 싶어.
- 목록 표에 번호 / 구분 / 국가 / 한 줄 후기 / 학교명 / 이름 이 다 있어.
- 페이지당 10건, 주소의 startPage=1~50 으로 넘어가. 엑셀 다운로드 기능은 없어.
- 목록 주소: (한줄소감 목록 페이지 주소를 붙여넣기)

[요청문에 꼭 담을 조건]
- 콘솔에 붙여넣으면 바로 실행되는 자바스크립트일 것
- startPage를 1부터 끝까지 fetch로 돌며 표에서 6개 열을 뽑을 것
- 페이지마다 0.3~0.5초 간격을 둘 것
- 결과를 CSV로 만들어 다운로드 (UTF-8 BOM, 쉼표·줄바꿈은 큰따옴표로 감싸기)
- 공개 목록만 사용하고 로그인·개인정보는 수집하지 않을 것

마지막에, 내가 새 채팅창에 그대로 붙여넣을 '최종 요청문' 하나를 완성해서 줘.

EXTENSION PROMPT
방금 콘솔에서 잘 작동한 이 코드를, 크롬 확장 프로그램으로 만들어줘.

(아래에 방금 콘솔에서 실행한 코드를 붙여넣기)

조건은 다음과 같아.
1. Manifest V3 확장으로 만들어줘. 파일은 manifest.json, popup.html, popup.js.
2. manifest에 host_permissions로 https://www.jbe.go.kr/* 접근 권한을 넣어줘.
3. 팝업에 [수집 시작] 버튼과 진행 상태(예: 12/50페이지)를 넣어줘.
4. 버튼을 누르면 위 코드가 실행되어 CSV가 다운로드되게 해줘.
5. 파일명은 한줄소감_2026.csv, 엑셀에서 한글이 안 깨지게 UTF-8 BOM으로 저장해줘.
6. 공개 목록만 사용하고 로그인·개인정보는 수집하지 않아.

각 파일(manifest.json, popup.html, popup.js) 전체 코드를 파일명과 함께 하나씩 제공해줘.
