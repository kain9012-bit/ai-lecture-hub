## 새 강의 올리는 법

1. `lectures/` 아래에 영문 폴더 생성 (예: `lectures/2026-11-principal-ai/`)
2. 폴더에 파일 넣기 — 이름 규칙
   - `slides.html` 강의안
   - `slides.pdf` 강의안 PDF
   - `practice.zip` 실습파일
3. `lectures.js` 배열 맨 위에 항목 하나 추가
4. 커밋·푸시 → 1~2분 뒤 웹페이지 자동 반영

## 폴더 구조

```
index.html        목록 페이지 (수정 불필요)
lectures.js       강의 목록 데이터 (새 강의 추가 시 수정)
lectures/<강의>/  강의별 파일
```

## 주의

- 파일 하나 100MB 초과 불가 (GitHub 제한)
- 한글 파일명 zip은 UTF-8 플래그로 압축해야 윈도우에서 안 깨짐
- 다른 사람의 강의자료, 개인정보가 담긴 파일은 올리지 않기
